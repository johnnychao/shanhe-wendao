# 師大問道 · 研究探險隊

在臺師大和平校區的卡通奇遇中，練習統計與研究思考。版本 0.4.0。

[開始探索](https://johnnychao.github.io/shanhe-wendao/?v=0.4.0)

## 怎麼玩

點「開始校園探索」後，用 WASD／方向鍵移動、Shift 奔跑，拖曳或滾輪調整視角；手機使用畫面方向鍵。靠近人物按 E 交談。「俯瞰校園」從上方看空間，「跟隨人物」回到步行。「行旅圖」可快速前往四個任務站；也可隨時直接進工作台。

目前四站：和平校門、圖書館前、誠大樓、運動場。主要建物、和平東路及師大路按公開地理資料簡化，周邊店面為虛構。場景提供室外探索，建築尚未開放室內；高度與立面為遊戲設計，不作實際導航。

角色採 KayKit 同系列四種造型，五官和衣帽更清楚；人物誌可旋轉、近看與切換動作，對話肖像取自實際模型。建築、圍牆、門柱、樹幹、家具與 NPC 會阻擋通行；斜走可沿牆滑動。

## 作答與評量

大學部與研究所各 W1／W2，共四個任務，其餘週次尚未製作關卡。「正式送出並保留本次作答」保存獨立快照；第一次可追溯的正式提交作主要評量，後續每次保留。相同內容重按不增加次數，修改後提交另存新次數。

資料仍在此網址的瀏覽器。請到「備份與恢復」定期下載 JSON，換裝置、瀏覽器或網址前先備份。教師評量包可另行匯入私人 Google Sheets，再以 ChatGPT 輔助評閱。此版沒有登入、自動雲端同步、正式分數或公開排行榜；教師名冊與私人設定不在本儲存庫。
