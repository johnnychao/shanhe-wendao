# 師大問道 · 研究探險隊

在臺師大和平校區的卡通奇遇中，練習統計與研究思考。版本0.7.0。

[開始探索](https://johnnychao.github.io/shanhe-wendao/?v=0.7.0)

## 本學期怎麼玩

大學部與研究所各開放第1–16週，共32個任務、32段人物故事。從「任務選單」選課程和週次，可先聽人物委託，也能直接進工作台。學生逐週累積同一分析包或測量證據包；每週都有可獨立開始的資料或模板。

大學部從資料字典、整理與圖表，進到t檢定、ANOVA、相關、固定兩個預測變項的迴歸、卡方、無母數方法選擇、除錯和個人專題。研究所從構念及題項，進到信度、效度論證、外部關係、EFA、公平性、同儕回覆及本人答辯。研究所第10、14–16週以文字證據作答，不強制SPSS；沒有取得的來源、真人意見或口述紀錄須如實標待補。

第9–16週新增64份原創材料：60人活動、48人服務台及160列八候選題合成資料，以及字典、語法、工作表與證據模板。資料彼此為不同樣本，不可依列號拼接；沒有真實學生或已驗證量表。原書、原課綱、出版社附檔及教師執行檔不公開。

## 作答與交件

先保存自己的初步判斷，再完成實作、AI查證與反思。分析關可貼完整多行SPSS Syntax，另寫實際輸出與自己的研究結果解讀，附上SPV、PDF或圖檔。網站只存文字，請在自己的SPSS執行；完整性檢查不會自動判定統計正確或計算成績。

「正式送出並保留本次作答」建立獨立快照。第一次可追溯正式提交為主要評量，後續每次另外保留；同內容重按不增加次數。可分別下載每次ZIP，或從「備份與恢復」下載完整JSON與Google Sheets／ChatGPT教師評量包。內容、語法、解讀和附件索引保留各次版本。

作答存在目前網址的瀏覽器，沒有學生登入或自動雲端同步。換裝置、瀏覽器、網址或清除網站資料前，先下載JSON。教師依指定私人管道收件，另將評量包匯入Google Sheets，再用ChatGPT協助人工評閱；公開排行榜仍未啟用。附件、備份及正式提交次數有上限，超量會拒絕新變更並保留舊紀錄。

## 校園漫遊

點「開始校園探索」，WASD／方向鍵移動、Shift奔跑，拖曳及滾輪看四周；手機用方向按鈕。靠近人物按E交談。可切換俯瞰／跟隨，行旅圖可前往和平校門、圖書館前、誠大樓及運動場四個任務站。

四種KayKit角色共用於主角、人物誌與對話肖像。校園有24位虛構居民、8位散步、50個日常話題與4個彩蛋。漫遊手帳按探險檔存此瀏覽器，不計成績，也不包含在課程JSON備份。建築、家具與NPC會阻擋通行；斜走可沿牆滑動，15棟建物的戶外三階可上下。室內尚未開放。

## 驗證與使用範圍

第5–8週8份語法已在本機SPSS22實跑並獨立核對，研究所第7週刻意冗餘題項產生的警告已在教材解釋。第9–16週12份起始語法與3個教學分支，最終執行皆error0，另有1,492項獨立核對。第14週原版刻意包含加法錯誤，學生須保存錯誤、修正及重跑證據；程式能執行不等於分析正確。

原第2–4週語法未列入本次SPSS實跑。全16週已有教材與工作台，正式試教、教師收件、SPSS桌面GUI／SPV另存及真手機／硬體GPU仍待驗證。這是零額外費用的教學遊戲原型，尚非大型商業遊戲；沒有臉部口型或多人連線。既有訂閱不代表使用了付費API。
