# 山河問道 · 研究探險隊

以武俠人物對話串連統計與研究思考的瀏覽器教學原型。版本 0.3.0。

[線上試玩](https://johnnychao.github.io/shanhe-wendao/)

## 開始探索

進入遊戲後，可在青溪境行走，或直接點「任務工作台」。WASD／方向鍵移動、拖曳調整視角、E 與附近人物交談；「行旅圖」提供四區驛行。

目前開放聽雨渡、觀瀾書院、竹隱資料亭、問心山亭，以及大學部與研究所各 W1／W2 共四個任務。其餘週次是課程方向，尚未製作關卡。

「人物誌」可查看沈行舟、阿澄、小衡、知秋四個實際 3D 人物，與場內共用同一模型。拖曳或按左右鈕轉身，選「近看」查看眉眼與衣髮，切換站姿、行走及暫停。手機可在面板內向下滑至人物控制；「角色肖像」摺頁另收 AI 概念畫。

## 作答保存與評量

「正式送出並保留本次作答」會保存一份獨立快照。第一次正式送出作主要評量，後續每次保留；相同內容重按不會重複增加次數。每份快照都可下載當時的答案與附件。完成檢核只表示活動資料齊備，不代表教師已核定成績。

資料保存在此瀏覽器。請定期到「備份與恢復」下載完整 JSON；換裝置、瀏覽器或網址前先備份。教師評量包包含歷次作品索引、作答證據、附件索引與規準，可由教师在私人試算表匯入並以 ChatGPT 輔助評阅。

此版本沒有學生登入、自動上傳、正式分數或公開排名；私人教師試算表與名冊不在這個儲存庫。不要在公開問題回報中貼學生資料、完整作品或私人連結。

## 目前限制

這是擬真方向的教學遊戲原型，尚未達大型商業遊戲的角色、場景與動畫品質。四人已有髮片、衣料皺褶與待機／行走，臉部表情、口型、布料物理及更精細裝束尚未製作。四張肖像為 AI 概念美術。軟體繪圖可能明顯卡頓，可直接進入工作台；硬體顯示卡與手機實機仍需補驗。

合成資料與參考操作供練習；網站不執行 SPSS，參考 Syntax 尚未在 SPSS 實跑。ChatGPT 建議與教師核定分开處理。
