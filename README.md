# 師大問道 · 研究探險隊

在臺師大和平校區的卡通奇遇中，練習統計與研究思考。版本 0.5.0。

[開始探索](https://johnnychao.github.io/shanhe-wendao/?v=0.5.0)

## 怎麼玩

點「開始校園探索」後，用 WASD／方向鍵移動、Shift 奔跑，拖曳或滾輪調整視角；手機使用畫面方向鍵。靠近人物按 E 交談。「俯瞰校園」從上方看空間，「跟隨人物」回到步行。「行旅圖」可快速前往四個任務站；也可隨時直接進工作台。

目前四站：和平校門、圖書館前、誠大樓、運動場。主要建物、和平東路及師大路按公開地理資料簡化，周邊店面為虛構。場景提供室外探索，建築尚未開放室內；高度與立面為遊戲設計，不作實際導航。

角色採 KayKit 同系列四種造型，五官和衣帽更清楚；人物誌可旋轉、近看與切換動作，對話肖像取自實際模型。建築、圍牆、門柱、樹幹、家具與 NPC 會阻擋通行；斜走可沿牆滑動。

15 棟建築正面均有可上下的三階戶外樓梯與門前平台。由最低階直接走上，往回走即可下階，不需跳躍；人物、影子和鏡頭一起升降，側邊護欄與後方牆面仍阻擋通行。

校園另有24位虛構學生、校友與附近居民，其中8位會散步。靠近按 E 或點「打招呼」，聊早餐、社團、讀書、運動與研究生活，共50個短話題。沿路藏著4個彩蛋；「漫遊手帳」提供提示，並記下打過招呼的人與找到的小故事。居民共用原有四種模型，依服色與比例作變化。

漫遊手帳按個別探險檔存在這個瀏覽器，不列入成績，也不包含在課程JSON備份。首次進站會保存沒有作答的空白探險檔，讓只漫遊的玩家重整也可繼續；如果無法儲存，對話與手帳會立即提示。

## 作答與評量

大學部與研究所各W1–4，共八個週任務；第5–16週尚未製作，現階段無法支撐完整學期。「正式送出並保留本次作答」保存獨立快照；第一次可追溯的正式提交作主要評量，後續每次保留。相同內容重按不增加次數，修改後提交另存新次數。

新增大學部「清理工坊的三本帳」「看得懂的描述展台」，使用18人原創合成資料，學習Compute／Recode／篩選、描述與圖表。工作台可貼完整多行SPSS Syntax，另外記錄實際輸出、自己的結果解讀及限制，附上SPV、PDF或圖檔；網站只保存文字，不執行SPSS、不自動判統計答案正確。

新增研究所「測量藍圖工坊」「題項試讀工作臺」，下載藍圖、題項與查證模板，累積同一證據包。前段不強制SPSS、真人專家或訪談；自我演練與AI意見須清楚標示。工作台「聽人物說明本週委託」提供短對話，也可跳過直接實作。

教材參考使用者提供的SPSS22教科書第2／3章、離線附檔與Coding with AI第8／9章；下載內容由本案另作合成案例與模板，沒有公開原書或原附檔。SPSS22語法尚待實跑與課堂驗證。每份探險檔有附件與備份容量上限，超量時保留原紀錄並提示；全學期雲端收件仍待完成。

資料仍在此網址的瀏覽器。請到「備份與恢復」定期下載 JSON，換裝置、瀏覽器或網址前先備份。教師評量包可另行匯入私人 Google Sheets，再以 ChatGPT 輔助評閱。此版沒有登入、自動雲端同步、正式分數或公開排行榜；教師名冊與私人設定不在本儲存庫。
