# Campus geographical data

© OpenStreetMap contributors — [ODbL 1.0](https://www.openstreetmap.org/copyright).

The complete adapted geographical database used by this game is provided as [campus-layout.json](campus-layout.json), under ODbL 1.0. Derived from OSM building bounds and road nodes; checked 2026-09-11. The JSON includes source way IDs and transformation parameters. Coordinates are reduced to half scale; building footprints are simplified to bounding rectangles, streets are simplified polylines, and heights are game estimates. Endpoints extended beyond source nodes are fictional continuations for the scene boundary.

Campus names and relative locations were cross-checked against [NTNU campus maps](https://www.ga.ntnu.edu.tw/ntnu_map/) and the [Department of Health Promotion and Health Education](https://www.he.ntnu.edu.tw/index.php/about/). Official map images have not been copied. Geometry, facades, decorations, colors, fictional shops and character stories are original game interpretations. This is not a survey, navigation service, official campus replica or endorsement. No Google Maps 3D mesh, imagery or derived geometry is included.
